# Checklist de Tarefa Agentica

Use este checklist antes de finalizar qualquer tarefa feita com agente no TrackVision.

## Antes de editar

- [ ] Identifiquei o repositorio correto.
- [ ] Rodei `git status --short --branch`.
- [ ] Li os arquivos relevantes.
- [ ] Entendi objetivo, contexto, restricoes e criterio de aceite.
- [ ] Separei suposicoes de fatos verificados.

## Durante a execucao

- [ ] Mantive o escopo da demanda.
- [ ] Nao reverti mudancas de outra pessoa.
- [ ] Evitei segredos, tokens e dados sensiveis.
- [ ] Atualizei documentacao quando necessario.
- [ ] Mantive commits pequenos e revisaveis.

## Antes de finalizar

- [ ] Rodei verificacoes adequadas.
- [ ] Expliquei qualquer verificacao que nao pude rodar.
- [ ] Conferi `git status --short --branch`.
- [ ] Preparei resumo com arquivos alterados.
- [ ] Registrei pendencias reais, se existirem.
